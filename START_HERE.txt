SOPORTE RÁPIDO
================================================================================

❌ "Cannot find module '@supabase/ssr'"
   → pnpm install @supabase/ssr @supabase/supabase-js

❌ "NEXT_PUBLIC_SUPABASE_URL is required"
   → Verifica .env.local tiene valores (sin comillas)

❌ "Access denied" en admin
   → Ejecuta SQL UPDATE para hacer admin (ver DESPLIEGUE_LOCAL.md)

❌ "Imagen no aparece"
   → Verifica bucket "productos" sea PUBLIC en Supabase Storage

Para más help → DESPLIEGUE_LOCAL.md (Troubleshooting section)
