# Nuevo El Salvador Shop

Plataforma e-commerce moderna desarrollada para la gestión de catálogo, ventas en línea y administración de pedidos.

## Tecnologías Principales

* **Frontend:** Next.js / React / Tailwind CSS
* **Backend:** Supabase
* **Lenguaje:** TypeScript

## Características

* Catálogo de productos interactivo con navegación por categorías.
* Carrito de compras y gestión de pedidos.
* Panel de administración para gestión de inventario.
